# GLY-166 listener implementation and review

Issue: [GLY-166 / T03.3](https://linear.app/getglyd/issue/GLY-166).
Base: merged [PR #4](https://github.com/Sigbound/glyd-compute/pull/4),
`40394019ed072971967f8fada30640be39bf3b35`. Branch: `gly-166-listener-limits`.
Linear records the uploaded head, PR and exact-head four-platform CI results;
local checks do not substitute for that gate.

## Delivered

Loopback-only client HTTP with strict bounded framing, exact Host and no-browser
origin policy, model-scoped token checks before body parsing/dispatch and every
response enqueue. Shared RAII connection, per-IP, handshake and rate admission
covers the client, TLS/bootstrap and local admin listener APIs. TLS has a combined
traffic ceiling and absolute deadlines; complete peer control records no longer
restart their timeout on partial reads. Failed frames poison and close the stream.

Native local admin IPC requires protected filesystem permissions, Unix peer UID
verification or a protected Windows pipe DACL, and a private random capability.
Only the authenticated bounded record API exposes commands. See
[listeners.md](../listeners.md) for exact limits and integration requirements.

## Review

Correctness/security review covered authentication ordering, malformed and duplicate
HTTP headers, length overflow, JSON limits, exact Host matching, browser origins,
connection release on all failures, shared admission state bounds, handshake byte
accounting, absolute frame deadlines, stale buffered TLS data, policy-ordered output,
admin permissions, capability encapsulation and native platform differences.

Review fixes made raw admin reads private, rechecked the private capability file
after accept and before returning a command, and permanently denied reuse after a
failed peer record. HTTP output uses only nonblocking writes while authorization
is locked; it waits outside that lock. Existing TLS verification is unchanged.

The separate complexity review retained direct standard-library networking and
RAII ownership, reused the HTTP and native IPC libraries, and removed a redundant
bootstrap wrapper and extra capability-tag computation. No configurable framework,
thread pool, runtime or speculative route/backend implementation was introduced.

## Validation

Pinned Rust 1.97.1: formatting; default/all-feature Clippy with `-D warnings`;
default/all-feature workspace tests and doc tests, with warning-as-error flags.
The suite contains 34 default and 35 all-feature tests, including 20 security tests.
New adversarial cases cover:

- Valid scoped HTTP dispatch; denied model/action and revoked token; rejected
  origin/fetch metadata, duplicate headers, transfer/content encoding, expectations,
  upgrades, oversized headers/body and malformed/duplicate-key JSON.
- Unauthorized artifact-shaped request refused before waiting for a body, with a
  sentinel proving no application dispatch; refused wildcard binding.
- Real loopback connection floods capped at four per IP with released slots;
  global and handshake caps and retained rate accounting; slow headers and bodies.
- A real enrolled TLS peer, a valid framed message and a slow-drip control frame;
  handshake traffic/deadline ceilings, idle bootstrap failure and admission release;
  invalid framed input followed by buffered plaintext cannot reuse the connection.
- Native admin socket/pipe access using the private capability; wrong capability,
  oversized record, incomplete record, duplicate endpoint refusal and Unix mode
  checks. Tests run as one OS user, not a separate cross-user penetration test.

Short deadlines are injected only inside tests; production limits remain fixed.
Connection counters and rejection/deadline behavior are tested; process RSS, CPU
quotas, inference performance and kernel flood protection are not measured.
CI retains all four platforms, early formatting/lint, warning failures, its
five-minute job cap, cache, fail-fast matrix and stale-run cancellation.

## Remaining gates

GLY-167 must wire shared budgets into every daemon listener, dispatch commands,
manage endpoint cleanup and maintain timers. GLY-168 supplies current remote
membership/epochs and GLY-169 reachability. M2 must bind trusted route/model
resolution to the requested scope, implement artifact/inference endpoints and
carry authorization into streaming/backends. The current HTTP subset is not the
complete OpenAPI contract and rejects errors by closing the connection.

The license remains undecided. No model, GPU, paid host or physical Raspberry Pi
was used. Linux ARM64 CI does not certify Pi inference. No M2 implementation starts
before the remaining M1 tasks and their review gate are complete.
