## Integrated paths checked

Enrollment: protected invitation -> pending key/fingerprint -> local approval ->
pinned TLS -> atomic membership/invitation consumption -> protected identity/config.

Steady state: explicit local address -> shared admitted TLS -> exact enrolled peer ->
strict registry record -> durable boot/epoch/sample checks -> expiring observation ->
local acknowledgement/fence -> independent maintenance and output/admission gates.

Loss/recovery: wrong pin or blocked route -> bounded failure -> next explicitly
configured route; authority expires independently. Restart durably advances authority
after successful binds and before admission. Work is cancelled; in-flight memory remains owned until trusted
local completion. No old KV state or ambiguous model execution is resumed.

Discovery: explicitly selected interface -> DNS-SD hint -> filtered untrusted output.
No path from a hint to membership, certificate replacement, a configured route,
resource eligibility, model permissions or backend execution exists.

Shutdown: close admission, clear approvals, drain, finish bounded I/O, join workers,
remove validated transient IPC only. Persistent identities, model data and locks stay.
All configured peer listeners share the original budget; adding interfaces cannot
multiply its limits.

## Correctness/security and complexity review

Reviewed trust-boundary parsing, signing-key ownership, certificate selection and
renewal overlap, authorization/output lock ordering, private state and cleanup,
clock/storage failure handling, bounded connection/thread/frame lifetimes, route
selection, stale topology and separation of discovery from trust.

Retained direct synchronous code and existing protocol/security helpers. Added only
native socket/interface APIs and DNS-SD protocol reuse for GLY-169. No speculative
scheduler, backend API, consensus, NAT traversal or discovery-to-trust automation.

Final validation requires formatting, default/all-feature Clippy and tests on Linux
x64, Linux ARM64, macOS and Windows, zero warning diagnostics, and a green exact PR
head. CI evidence and timings are attached in Linear after completion.
