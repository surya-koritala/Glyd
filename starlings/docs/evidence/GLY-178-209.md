# Whole-request queue and CPU placement checks

`cargo test -p compute-core --test routing --locked --offline` covers exact profile,
manifest/build matching, memory reservation, fast/slow fixture selection, client
fairness, bounded queue/result storage, explicit expiry delivery, cancellation/drain,
stale/offline nodes, replacement builds and independent node withdrawal. ARM64 CPU
fixtures have one system pool and no layer capability. All costs are synthetic
inputs, not hardware benchmarks. Workspace Clippy denies warnings.

The pure router is not yet wired to the generation daemon, native qualification
records or catalog pins. Required real direct/proxy and one/two-worker comparisons
are still pending, as are Raspberry Pi sensor integration and physical tests.
No model/backend/hardware qualification is inferred from a fixture evidence digest.
