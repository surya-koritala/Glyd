# GLY-170: immutable manifests and local approval

Implemented: rehash declared protected source files with exact lengths; pinned
full revisions; manifest identity including precision/profile/scope/license and
layer/component inventory; immutable registration; independent local-use and
redistribution approval; durable revocation; CLI inspect/seal/register/show/check.

Validation: catalog tests alter weight/config/tokenizer/template bytes and the
execution profile and require a different identity. They cover exact-length
hashing, unknown/unsafe paths, symlinks, missing inventory, mutable revisions,
tampered identities, fixture rejection, restart, exclusive ownership, approval
and redistribution denial. A separate CLI process test runs the complete local
approval/revocation flow and asserts no inference claim. All tests use synthetic
bytes, not a model. Final commit/CI/PR evidence is linked in Linear.

Review: reuse protocol validation, SHA-256, protected atomic files and StateLock;
no dependency, network provider, model runtime or parser is added. Filesystem
paths from manifests are validated and opened through protected handles, never
concatenated into network URLs or shell commands. Approval is separate from
content provenance and cache readiness.

Remaining: provider revision resolution, artifact import/download, quotas and
runtime integration continue in GLY-171/172 and the backend tasks. Operator-supplied
layer inventory is not independent tensor enumeration or numerical qualification.
Pi hardware testing remains GLY-210. No model, GPU or external backend ran.
