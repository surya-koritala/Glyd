- The decode over a bf16 KV cache (`GLYD_KV=bf16`, the default) reads its keys and values faster in the 12-bit pages' decode kernel it now shares (`glyd_gpu_kv_decode_bf16`). Since it took that kernel, gemma-4-12B decoded 12.7% slower on an A100 for one user and 36% slower for eight, Qwen3.5-0.8B 8.8% and 21%. The kernel read a page of a bf16 cache a value at a time, each value's place through the block table; it now reads a page's keys and values at once in an instance of the kernel of its own, and launches a call's CTAs split by split so the ones with work start first. The outputs are the same bits as the 12-bit pages', as before. The speed after: not measured yet (`glyd-engine attndecode` times a call against the engine's decode before; `glyd-engine kvshapes` holds a batch of sequences in one call to each alone and to the pages, bit for bit).
