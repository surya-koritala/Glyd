- The expert cache reports what each mixture-of-experts layer did in every step: experts asked for and found on the GPU, misses copied or computed on the CPU, the CPU's pairs, the bytes read from the computer's memory and the time spent waiting. `/stats` adds an `"experts"` list, one entry a layer, once a model with experts in the computer's memory has run.
- A step of many users reads each missed expert once: Kimi-K3's and DeepSeek-V4's FP4 experts computed on the CPU are read once for all the rows routed to them, and DeepSeek-V4's release experts can now be computed on the CPU at all (before, every miss was copied to the GPU).
- The choice between copying a missed expert and computing it on the CPU counts its rows: the first row of an expert costs its bytes, each further row only its arithmetic, both measured as the model runs.
