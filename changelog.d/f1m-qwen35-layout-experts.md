- The Qwen3.5 layout with experts runs on the description executor: a layer whose feed-forward is a mixture of experts (a softmax router, the chosen experts renormalised, a shared expert gated by a sigmoid) runs the experts' operation in the MLP's place. Its block is made from the layer kind and its tensors' roles by one loader (`dynamic::experts`), which any family whose description names its experts a tensor each can use: lossless where the level is, or at kestrel, swift and wren. A small random model of the layout is a logits case (`qwen35moe`) held to the CPU reference of the layer kinds. Part of #333.
- The Kimi family's newer config (its sparse attention, `dsa_config`) runs on the description executor: on the latent attention layers it names, an indexer of a key a token picks the tokens the attention reads, its keys RMS-normed or LayerNorm-ed as the config says. The latent attention's indexer takes the keys' norm and pooled or per-token keys as options of the one operation. A second small random model of the family is a logits case (`kimi-dsa`) held to the CPU reference of the layer kinds. Part of #333.
