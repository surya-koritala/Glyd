- Models with recurrent layers on the description executor (Qwen3.5 / 3.8 and Nemotron-H) now find a conversation's start that any earlier request ran: their states are kept every chunk of a prompt, in a pool of fixed size made at load (512 MB by default, `GLYD_ENGINE_STATE_SNAP_MB`; boundaries every `GLYD_ENGINE_STATE_EVERY` tokens, the chunk by default), under the name of the block ending there, and a request goes on from the newest such boundary whose attention blocks are held. On an RTX 4080 with Qwen3.5-9B, eight conversations with the same 4k start have their later turns' first token in 0.134 s where they took 1.141 s, and make 233.2 tokens/s in all where they made 107.7; one conversation's later turns 0.10-0.13 s where they took 0.93 s, since Qwen3.5's chat template writes an earlier reply back without the `<think>` block its generation prompt ended with. Loads with nothing in common are unchanged (`benchmarks/gpu/rtx4080-state-snapshots-2026-11-22`).
- The planner counts the second copy of a recurrent model's states kept at each prompt's end, and the pool, in the memory it plans.
