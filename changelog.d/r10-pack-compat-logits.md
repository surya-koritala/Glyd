- Pack-format compatibility (R10): every saved format Glyd has written is held in `tests/data/packs` (16 small saves, 1.71 MB: glyd-v1 to glyd-v7, every layout and level, now with glyd-v2's experts, glyd-v5's packed table, glyd-v7 at penguin and the exact four-bit i4x), and each that holds a model is run on the CPU reference on every merge, its logits held to a digest recorded for it (`glyd-engine packcheck`); on the GPU job the same saves are decoded by the GPU library and held to the same digests (`packcheck --gpu`). A change that reads an old save to other weights or other logits fails there. `packcheck --engine` makes the formats the engine loads a downloaded or cached directory in (glyd-v7 at penguin, kestrel, swift, wren and hummingbird) from random models of the families published in them, loads each from the saved directory and holds it to the bits of the same model packed as it loads. The GPU job now runs `packcheck --engine` on every merge as well; a format whose digest is not recorded fails it by name with the command that records one. Part of #231.
