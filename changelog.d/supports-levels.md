- `glyd-engine supports MODEL[:LEVEL]` answers from the same table as `fit` and `run`: every family the engine runs (Qwen3, Qwen3.5 to 3.8, Gemma 4, GLM, Kimi, DeepSeek, Muse, Nemotron), at a level where one is given (`--lossy` is `:kestrel`). A level the family does not run is refused with the levels it does (`Qwen3.5-9B (Qwen3.5) runs at the kestrel, swift and wren levels in this engine, not penguin`); it used to refuse every model that is not Qwen3, and took `MODEL:LEVEL` as a directory name.
