- The five-bit level is now named **linnet** (it was "swift" before v0.36.0). `MODEL:linnet`, `glyd fit`, `glyd models` and the pre-packed
  repos' names (`glyd/NAME-linnet`) use the new name. The earlier name is still read where it is already written: a save's manifest, a
  pre-packed repo's name, and a tag on a command line; nothing writes it.
