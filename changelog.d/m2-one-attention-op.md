- One attention operation for every dense-attention model on the description executor (Gemma 4, Qwen3.5 and Qwen3.8 dense, Nemotron-H, Muse Spark): its head width, heads, norms, rotary, window, scale, soft-cap, output gate and rounding points come from the model's layer kinds, and one set of kernels (heads of 64, 128, 256 and 512) runs it.
- A prompt chunk over 12-bit KV pages reads them where they are (`glyd_gpu_kv_prefill`) instead of unpacking them to bf16 first; over bf16 caches the same kernel runs (`glyd_gpu_attn_prefill`, C API 20), so a prompt's logits are the same bits on either cache. Logits move in their last bits from before (sums in another order), within the reference's bounds.
- Nemotron-H's attention layers keep half the GPU memory a token they did: their keys and values are held apart, where a second buffer of the same size was made and never read.
