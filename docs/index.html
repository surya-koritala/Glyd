Glyd

Glyd is an LLM inference engine written in Rust. You name a model and it works out how to fit it on your GPU: lossless compression in GPU memory first, then lossy levels, then experts in RAM or on NVMe, then more GPUs. It also holds the file codec and store the project started as. Apache-2.0.

Where things are

  • README: what runs today, the measurements with their logs, and the known limits.
  • ROADMAP: the milestones, one GitHub issue per item.

  • DETAILS: the older measurements for the GPU package and the codec.
  • Releases.

Status

Rust, C ABI, CLI; v0.33.1, November 2026. On Linux with an NVIDIA GPU the installer puts Glyd's engine in place without Python, and glyd run uses it. The engine runs on NVIDIA GPUs of the Ampere generation or newer, on Linux x86_64 with driver 580 or newer. The README has the list of models and the limits.
